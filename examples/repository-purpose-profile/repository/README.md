# Packaging Tutorial Sample

This repository is editable source material for a packaging tutorial. Readers copy and modify its metadata while following the surrounding lesson; it is not presented as a conventional package with its own end-user installation journey.

## Usage

```bash
python -m sample_project
```

The command prints a small confirmation so the tutorial can verify that its generated package layout works. The annotated project metadata is intentionally the teaching surface for dependency and installation concepts.

See `docs/tutorial.md` for the lesson context and the boundaries of this sample.
